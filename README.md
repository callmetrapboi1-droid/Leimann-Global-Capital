# Leimann Global Capital — Real Estate & Swiss Wealth Management

A luxury real estate and multi-generational capital preservation web application built with **Next.js 15 (App Router)**, **Tailwind CSS**, **TypeScript**, and **WebGL Shader Effects**.

## Features

- **Atmospheric WebGL Shader**: Platinum metallic grain shader that shifts dynamically with user mouse movement.
- **Trophy Real Estate Portfolio**:
  - Filter by jurisdiction (Switzerland, United Kingdom, Asia Hubs).
  - Dynamic multi-currency converter (`CHF`, `USD`, `EUR`, `THB`).
  - High-res interactive property lightbox detailing interior space, yields, and capital appreciation.
- **Interactive Wealth & Real Estate Yield Calculator**:
  - Simulate capital preservation and returns across 5 to 30 years.
  - Custom allocation between tangible real estate and liquid Swiss wealth reserves.
- **Glassmorphism Bento Grid**:
  - Interactive spotlight reflection on hover for wealth management disciplines.
- **Secure Investor Portal & Consultation Modal**:
  - Client token authentication login.
  - Confidential property dossier dispatcher.
  - Private wealth consultation scheduler.
- **Quarterly Macro Review Subscription**:
  - Interactive email subscription with instant feedback.
- **Responsive Architecture**:
  - Ultra-luxury aesthetic optimized across mobile, tablet, and ultra-wide displays.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Production Build

```bash
npm run build
npm start
```
